# Blob

A Tauri desktop app around a blob avatar (generated by [blobatar.dev](https://blobatar.dev)) that lives an autonomous, simulated life, with a private layer and a shared public garden.

[![build](https://github.com/PerretWilliam/blob-land/actions/workflows/build.yml/badge.svg)](https://github.com/PerretWilliam/blob-land/actions/workflows/build.yml)
[![license: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

## Structure

This is a pnpm monorepo:

- `apps/desktop` — Tauri + React/Vite/TypeScript client
- `apps/api` — Cloudflare Worker (Hono) + D1, server-authoritative over accounts and unions
- `packages/sim` — pure TypeScript simulation engine, shared between the desktop client and the Worker

See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the technical stack and data model, and [docs/DECISIONS.md](docs/DECISIONS.md) for the reasoning behind the choices already made.

## Development

```bash
pnpm install
pnpm --filter @blob-land/desktop tauri dev
pnpm --filter @blob-land/api dev
pnpm --filter @blob-land/sim test
```

Each package also has its own README with package-specific commands.
